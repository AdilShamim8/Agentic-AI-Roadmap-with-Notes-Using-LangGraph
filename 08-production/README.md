# 08 - Production

Deploy, monitor, and scale agentic systems that run in production. By the end of this module, you can ship an agent to LangGraph Platform or self-hosted Docker, configure checkpointing for durability, optimize cost, and implement governance.

## What you will learn

- Deploying to LangGraph Platform and self-hosted Docker
- Checkpointing and durable execution
- Cost optimization: model routing, token budgeting, caching
- Governance: permissioned tools, audit logs, PII handling, compliance
- Continuous improvement: feedback loops, A/B testing, agent versioning
