# Learning paths

Pick the path that matches your background. Each path tells you what you already know, what you need to learn, and the shortest route through the curriculum.

## The paths

- [From ML engineer](from-ml-engineer.md) - easiest transition; add agents and evals to your existing stack
- [From backend engineer](from-backend-engineer.md) - add AI orchestration to distributed systems experience
- [From data scientist](from-data-scientist.md) - evaluation is your superpower; add engineering rigor
- [From frontend engineer](from-frontend-engineer.md) - backend first, then AI, then full-stack agents
- [From data engineer](from-data-engineer.md) - pipelines and persistence map directly; add orchestration
- [From zero](from-zero.md) - the complete beginner path, no assumptions

## How to use a path

1. Read the "What you already have" section. Skip anything you already know; the path will tell you which modules to skip.
2. Read the "What you need to learn" section. This is your gap list.
3. Follow the suggested path in order. Each module links to the next.
4. Build the two projects suggested at the end of the path. Projects consolidate learning.
5. When you finish, read [the field guide](../field-guide/) for career guidance.

## Time commitment

Each path estimates weeks at 2-3 hours per day. If you have more time, you go faster; if you have less, you go slower. The phases are checkpoints, not deadlines. Do not rush; the eval suite at the end of each module is the real test, and you should not move on until you can pass it.
