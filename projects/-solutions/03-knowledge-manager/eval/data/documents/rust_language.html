The Rust Programming Language

Rust was designed by Graydon Hoare at Mozilla Research starting in 2006. Mozilla sponsored the project from 2009 and announced it publicly in 2010. The first stable release, Rust 1.0, shipped on 15 May 2015.

Rust's central innovation is the ownership system, enforced at compile time by the borrow checker. The system prevents data races and use-after-free errors without a garbage collector. The three rules of ownership: each value has one owner, when the owner goes out of scope the value is dropped, and borrows are either shared or mutable but never both.

Rust uses the Cargo package manager, hosted on crates.io. Editions (2015, 2018, 2021, 2024) allow the language to evolve without breaking existing code.

The Rust Foundation, founded in 2021, is a non-profit based in San Francisco. Members include Amazon, Google, Microsoft, Huawei, and Mozilla. Rust has been voted "most loved language" in the Stack Overflow Developer Survey for many consecutive years.
