# Reference solutions

This directory holds reference solutions for the projects in [projects/](../). Each solution lives in a subdirectory named after the project (e.g., `01-research-agent/`).

## Spoiler warning

Do not look at these solutions until you have a working implementation of your own. The learning is in the building, not in the reading. If you look at the solution first, you will not learn the patterns; you will only learn to read the patterns.

## When to use these

- You have built your own implementation and want to compare.
- You are stuck and have spent at least 4 hours trying to unstick yourself.
- You have shipped your implementation and want to see an alternative approach.

## Status

Reference solutions are added over time by contributors. If you have built a project that meets the eval rubric and want to contribute it as the reference, open a PR. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the process.
