# 05 - Agentic patterns

The canonical agent architectures and the decision framework for choosing between them. By the end of this module, you can implement every major pattern and diagnose which one fits a given problem.

## What you will learn

- ReAct, plan-and-execute, reflexion, supervisor, swarm, hierarchical, map-reduce
- The decision framework: which pattern for which problem
- The failure modes unique to each pattern and the mitigations
- How to combine patterns (supervisor of reflexion agents, map-reduce of plan-and-execute)

- [02 Plan-and-execute](02-plan-and-execute.md) - decompose, execute, replan
- [03 Reflexion](03-reflexion.md) - self-critique and retry
- [04 Supervisor](04-supervisor.md) - one router, N specialists
- [05 Swarm](05-swarm.md) - peer-to-peer handoffs
- [06 Hierarchical](06-hierarchical.md) - supervisors of supervisors
- [07 Map-reduce](07-map-reduce.md) - fan out, process, fan in
- [08 When to use which](08-when-to-use-which.md) - the decision guide
