# 07 - Multi-agent and A2A

Scale from single-agent to multi-agent systems using LangGraph's native patterns and the A2A protocol for cross-framework interop.

## What you will learn

- Multi-agent architectures: supervisor, swarm, hierarchical, market-based
- Agent handoffs with correct context transfer
- The A2A protocol: Agent Cards, task lifecycle, inter-agent messaging
- Cross-framework interop: LangGraph consuming OpenAI Agents SDK and CrewAI agents via A2A

## Chapters

- [01 Multi-agent architectures](01-multi-agent-architectures.md) - the patterns and when each fails
- [02 Agent handoffs](02-agent-handoffs.md) - context transfer, state reset, handoff failure handling
- [03 A2A protocol](03-a2a-protocol.md) - the spec, Agent Cards, task lifecycle
- [04 A2A agent cards](04-a2a-agent-cards.md) - exposing and consuming agents via A2A
- [05 Cross-framework interop](05-cross-framework-interop.md) - LangGraph <-> OpenAI Agents SDK <-> CrewAI
- [06 Agent marketplaces](06-agent-marketplaces.md) - emerging trends
